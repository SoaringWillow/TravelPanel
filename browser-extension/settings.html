TravelPanel Clipper

Settings

Default: https://travelpanel.vercel.app. Change this if you're running a self-hosted version.

Keyboard shortcut

Press Alt+Shift+S (Mac: Option+Shift+S) to save the current page without opening the popup. You can customise this at chrome://extensions/shortcuts.

Right-click to clip

Right-click any page or link and choose Save to TravelPanel to clip it.
