How to use
  • Navigate to any travel inspiration page (YouTube, Instagram, blogs, etc.)
  • Click the TravelPanel icon in your browser toolbar
  • Select a board (or save to Inbox), then click Save Clip
  • Claude AI will automatically extract locations and travel insights
  • Right-click any link → Save to TravelPanel to clip without visiting
About
  • Version 1.0.0 — TravelPanel Browser Extension
  • No data is sent to third parties. All clips go directly to your TravelPanel instance.
  • Extension source is part of the TravelPanel open-source codebase at browser-extension/
