TravelPanel Extension
Settings

Enter the URL where your TravelPanel app is deployed. This is where the extension will send saved links.

How to use

After saving your app URL:

  1. Navigate to any travel page (Instagram, YouTube, blogs…)
  2. Click the TravelPanel icon in your browser toolbar
  3. Click Save to TravelPanel
  4. Choose a board in the TravelPanel save dialog that opens
Finding your app URL

If deployed on Vercel, your URL looks like https://my-project.vercel.app. You can also use a local development URL like http://localhost:3000 for testing with the dev server running.
