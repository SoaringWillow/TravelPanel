About

TravelPanel Clipper sends any web page URL to TravelPanel's share flow, where Claude extracts locations, tips, warnings, and travel wisdom from the page.

Supported: Instagram, YouTube, Xiaohongshu, TikTok, Bilibili, and any web page.
Right-click any link or image to clip it without opening the popup.
