TravelPanel

Extension Settings

Set this to your deployed TravelPanel URL. Use http://localhost:3000 for local development or your Vercel/production URL.

How to use

  1. Click the TravelPanel icon in your browser toolbar on any travel page.
  2. Hit Save to TravelPanel — it opens the app's clip flow in a new tab.
  3. Right-click any page or link → ✈️ Clip this … to TravelPanel for quick saves.
  4. The app extracts locations, tips, and wisdom from the page automatically.

Safari Web Extension

To use this extension in Safari, open a terminal and run:

xcrun safari-web-extension-converter /path/to/browser-extension

Then open the generated Xcode project and build the Safari extension target.
