🔗 TravelPanel URL

Paste the URL of your running TravelPanel app. Use localhost:3000 for local dev.

⌨️ Keyboard Shortcut

Default shortcut to open the clipper popup:
Mac: ⌘ Shift T   Windows/Linux: Alt T

Override via chrome://extensions/shortcuts (Chrome) or about:addons → Manage Extension Shortcuts (Firefox).

🛠 Installation (Sideload)

  1. 1 Clone or download the browser-extension/ folder from the TravelPanel repo.
  2. 2 Generate icon PNGs by running node generate-icons.js inside the folder.
  3. 3 Chrome/Edge/Brave: Go to chrome://extensions, enable Developer mode, click Load unpacked, and select the browser-extension/ folder.
  4. 4 Safari (macOS 14+): Run xcrun safari-web-extension-converter browser-extension/ in Terminal, then open the generated Xcode project and build to install.
  5. 5 Pin the extension to your toolbar, click it, and enter your TravelPanel URL above.
