How to use

  1. Browse to any travel-inspiration page (Instagram, YouTube, Xiaohongshu, etc.)
  2. Click the TravelPanel icon in your toolbar
  3. Hit Save to TravelPanel — the clip opens in a new tab so you can pick a board
  4. Right-click any page or link and choose Save to TravelPanel for a faster shortcut
