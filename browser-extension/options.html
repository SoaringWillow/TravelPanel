✈️ TravelPanel Clipper

Browser Extension Settings

The URL where your TravelPanel app is deployed — for example, https://your-app.vercel.app

How to use

  1. Browse to any travel blog, Instagram post, YouTube video, or 小红书 page.
  2. Click the TravelPanel icon in your toolbar (or right-click → Clip this page to TravelPanel).
  3. The TravelPanel share page opens — choose a board and save.
  4. AI automatically extracts locations and travel wisdom from the page.

Safari (macOS / iOS)

Convert this extension for Safari using:
xcrun safari-web-extension-converter /path/to/browser-extension
Then open the generated Xcode project and run it.
