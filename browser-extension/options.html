Tips

  • ⚡ Quick Clip — opens the save page immediately, no preview.
  • 🔍 Preview — calls the AI to extract locations & insights before saving.
  • 🖱️ Right-click any link to clip it directly via the context menu.
  • 📱 On iOS, use the Share Sheet extension to clip while browsing.
