TravelPanel Clipper

Browser Extension Settings

TravelPanel App URL

Your deployed TravelPanel URL. The extension opens this app whenever you clip a page.

How to clip
  1. Browse to any travel inspiration page (Instagram, YouTube, blogs…)
  2. Click the TravelPanel pin icon in your toolbar
  3. Hit Save to TravelPanel — a new tab opens in your app
  4. Claude AI extracts locations and wisdom from the page
Right-click shortcut: Right-click any page or link → Clip to TravelPanel
Keyboard shortcut: Alt+Shift+S (customize at chrome://extensions/shortcuts)
Using in Safari

Safari supports the same WebExtension standard. Convert this extension with Apple's CLI tool:

xcrun safari-web-extension-converter /path/to/browser-extension \
  --project-location ../ios/App \
  --app-name TravelPanelClipper

Open the generated Xcode project, build, then enable the extension in Safari → Settings → Extensions.

Installing in Chrome / Edge
  1. Go to chrome://extensions
  2. Enable Developer mode (top right toggle)
  3. Click Load unpacked and select the browser-extension/ folder
  4. Pin the TravelPanel icon to your toolbar
