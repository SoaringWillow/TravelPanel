Install in Safari (macOS)

Safari requires converting the extension through Xcode once:

  1. Install Xcode from the Mac App Store
  2. Run: xcrun safari-web-extension-converter /path/to/browser-extension
  3. Open the generated Xcode project and build it (⌘B)
  4. In Safari → Settings → Extensions, enable TravelPanel Clipper

Install in Chrome / Edge

  1. Go to chrome://extensions
  2. Enable Developer mode (top right toggle)
  3. Click Load unpacked and select the browser-extension/ folder
  4. The TravelPanel icon appears in your toolbar — pin it for quick access
