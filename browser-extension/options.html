How to install (Chrome)

  1. 1
    Open Chrome and go to chrome://extensions
  2. 2
    Enable Developer mode (top-right toggle)
  3. 3
    Click Load unpacked and select the browser-extension/ folder from the TravelPanel project
  4. 4
    Click the TravelPanel icon in your toolbar, open Settings, and paste your app URL above

How to install (Safari)

  1. 1
    Install Xcode command line tools: xcode-select --install
  2. 2
    Convert this extension: xcrun safari-web-extension-converter browser-extension/
  3. 3
    Build and run the generated Xcode project, then enable the extension in Safari → Settings → Extensions
