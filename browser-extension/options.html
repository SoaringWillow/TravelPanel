TravelPanel Clipper

Extension Settings

Your deployed TravelPanel URL. Use http://localhost:3000 for local dev.
How it works
1. Browse any travel page (Instagram, YouTube, Xiaohongshu, etc.)
2. Click the TravelPanel icon in your toolbar
3. Choose a board and hit Clip to TravelPanel
4. Claude extracts locations + wisdom from the post automatically

Safari users: Convert this extension using Xcode's xcrun safari-web-extension-converter command after cloning the repo.
