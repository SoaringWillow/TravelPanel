How to install
This extension isn't on the Chrome Web Store yet. Load it manually in developer mode.
  1. Open Chrome and go to chrome://extensions
  2. Enable Developer mode (top-right toggle)
  3. Click Load unpacked and select the browser-extension/ folder from the TravelPanel repo
  4. Pin the extension to your toolbar and set your deployment URL above
