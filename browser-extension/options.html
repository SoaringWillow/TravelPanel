Installation

1
Open Chrome and go to chrome://extensions
2
Enable Developer mode (top-right toggle)
3
Click Load unpacked and select the browser-extension/ folder from the project
4
Pin the TravelPanel icon to your toolbar — then press Alt+T on any travel page
5
For Safari: use xcrun safari-web-extension-converter browser-extension/ in Xcode (macOS only)
Settings saved!
