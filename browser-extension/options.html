TravelPanel Clipper

Extension Settings

The URL of your deployed TravelPanel app. Leave as default if you're using the hosted version.

How to use

Navigate to any travel post on Instagram, YouTube, TikTok, Xiaohongshu, or any website. Click the TravelPanel Clipper extension icon in your toolbar to save it.

The clip opens in TravelPanel where you can choose a board and watch the AI extract locations and travel wisdom from the content.

Self-hosting

If you're running TravelPanel locally, set the app URL to http://localhost:3000.
