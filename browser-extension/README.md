# TravelPanel Clipper — Browser Extension

Save travel inspiration from any website to TravelPanel with one click.

## Features

- **One-click clip**: Click the extension icon to clip the current page to TravelPanel
- **Context menu**: Right-click any page or link → "Clip to TravelPanel"
- **Keyboard shortcut**: `Cmd+Shift+S` (Mac) / `Ctrl+Shift+S` (Windows/Linux) for instant clip without opening the popup
- **Platform detection**: Recognises WeChat, Xiaohongshu, Douyin, and Bilibili links
- **Configurable**: Works with any TravelPanel deployment (Vercel, localhost, custom domain)

## Setup

### 1. Generate icons (one-time)

```bash
cd browser-extension
node generate-icons.js
```

This creates `icons/icon16.png`, `icon32.png`, `icon48.png`, `icon128.png` with zero npm dependencies.

### 2. Load the extension in Chrome

1. Open Chrome and go to `chrome://extensions`
2. Enable **Developer mode** (top-right toggle)
3. Click **Load unpacked**
4. Select the `browser-extension/` directory

The TravelPanel pin icon will appear in your extensions toolbar.

### 3. Configure your TravelPanel URL

1. Click the extension icon → click the gear (⚙) icon
2. Enter your TravelPanel URL (e.g. `https://your-app.vercel.app` or `http://localhost:3000`)
3. Click **Save**
4. Optionally click **Test connection** to verify

## Usage

### Clip a page
Navigate to any travel page (Instagram, YouTube, Xiaohongshu, etc.) and:
- Click the **TravelPanel pin icon** in the toolbar → click **Clip to TravelPanel**
- **Or** press `Cmd+Shift+S` (Mac) / `Ctrl+Shift+S` for instant clip

TravelPanel will open in a new tab with the URL pre-filled in the import dialog.

### Clip a specific link
Right-click any link on the page → **Clip link to TravelPanel**.

## How it works

The extension opens TravelPanel with `/?import=<URL>`. This triggers the import sheet in the TravelPanel web app, which:
1. Fetches the page and extracts locations + substance (tips, warnings, wisdom) using Claude AI
2. Shows a preview for you to review
3. Lets you add notes and choose which board to save to

All data is stored locally in your browser's IndexedDB — no separate account required.

## Safari Conversion (macOS)

```bash
xcrun safari-web-extension-converter browser-extension/ \
  --project-location . \
  --app-name TravelPanelClipper
```

Then open the generated Xcode project and run the app to install the extension.

## Development

The extension uses only vanilla JS with the Chrome Extensions API — no build step needed.
Edit files and click **Reload** on the extension card in `chrome://extensions`.

### File structure

```
browser-extension/
  manifest.json       — Extension config (Manifest V3)
  popup.html/css/js   — Toolbar popup UI
  background.js       — Service worker (context menus, keyboard shortcut)
  options.html/css/js — Settings page
  icons/
    icon.svg          — Source SVG
    icon16.png        — Generated by generate-icons.js
    icon32.png
    icon48.png
    icon128.png
  generate-icons.js   — Zero-dep Node.js PNG generator
```
