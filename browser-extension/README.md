# TravelPanel Clipper — Browser Extension

Save any travel URL to your TravelPanel boards in one click, directly from Chrome or any Chromium-based browser (Edge, Arc, Brave). A companion Safari Web Extension can be built from these same sources using Xcode.

## Features

- **One-click clip** — opens the TravelPanel `/share` page pre-filled with the current URL and page title, so the full substance-extraction flow runs automatically.
- **Platform detection** — recognises WeChat, Little Red Book (Xiaohongshu), Douyin/TikTok, Bilibili, and generic web pages.
- **Already-saved badge** — the popup remembers which URLs you've clipped (stored locally) and shows a green indicator so you don't duplicate clips.
- **Keyboard shortcut** — `Alt+Shift+S` (Windows/Linux) or `Ctrl+Shift+S` (macOS) opens the popup instantly. Customisable in `chrome://extensions/shortcuts`.
- **Configurable URL** — works with any deployment of TravelPanel (local dev, Vercel preview, or production).

## Installation (Chrome / Chromium)

1. Clone or download this repository.
2. Open **chrome://extensions** in your browser.
3. Enable **Developer mode** (toggle, top-right).
4. Click **Load unpacked** and select the `browser-extension/` folder.
5. The ✈ TravelPanel icon appears in the toolbar. Pin it for easy access.

### First-time setup

Click the ⚙ settings icon (or right-click the toolbar icon → *Options*) and confirm the **TravelPanel URL** matches your deployment:

| Environment | URL |
|---|---|
| Local dev | `http://localhost:3000` |
| Vercel preview | `https://your-branch.vercel.app` |
| Production | `https://travelpanel.vercel.app` |

## Usage

1. Browse to any travel post (Instagram, YouTube, Xiaohongshu, TikTok, blogs…).
2. Click the ✈ toolbar icon (or press `Alt+Shift+S`).
3. The popup shows the page title, URL, and detected platform.
4. Click **Save to TravelPanel** — the extension opens the `/share` page in a new tab.
5. Pick a board and confirm. Claude extracts locations + substance in the background.

## Regenerating icons

The icons are generated by a small pure-Python script (no dependencies):

```bash
cd browser-extension/icons
python3 generate.py
```

## Safari Web Extension

To ship this as a Safari extension on macOS / iOS:

1. Open Xcode → **File → New → Project → Safari Extension App**.
2. Choose **Convert Existing Extension** and point it at the `browser-extension/` folder.
3. Xcode wraps the Manifest V3 files into a native App Extension target automatically.
4. Build & run. Enable the extension in **Safari → Settings → Extensions**.
