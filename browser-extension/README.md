# TravelPanel Clipper — Browser Extension

Clip any travel webpage into your TravelPanel boards with one click. Works in Chrome, Edge, Brave, and Safari (via Web Extensions API).

## Quick Start

### 1. Generate icons (one-time)

```bash
cd browser-extension
npm install sharp
node generate-icons.js
```

### 2. Load in Chrome / Edge / Brave

1. Open `chrome://extensions` (or `edge://extensions`)
2. Enable **Developer mode** (top-right toggle)
3. Click **Load unpacked**
4. Select the `browser-extension/` folder

### 3. Configure

1. Click the extension icon → the settings prompt appears (first launch)
2. Enter your TravelPanel URL, e.g. `https://your-app.vercel.app`
3. Click **Save** then **Test connection** to verify

---

## How it works

```
User clicks extension icon
        │
        ▼
Popup shows current page title + URL
        │
        ├─ Background: calls /api/import to preview
        │   extracted locations + insights
        │
User clicks "Clip this page"
        │
        ▼
Opens /share?url=...&title=... in a new tab
        │
        ▼
Share page: user picks a board → saved to IndexedDB
        │
        ▼
Background enrichment: AI extracts substance + spots
```

## Features

| Feature | Description |
|---|---|
| **One-click clip** | Click the toolbar icon to open the clipper popup |
| **Extraction preview** | See extracted locations and insights *before* saving |
| **Context menu** | Right-click any page or link → "Clip to TravelPanel" |
| **Platform detection** | Detects Instagram, YouTube, Xiaohongshu, TikTok, TripAdvisor, etc. |
| **Settings page** | Configure TravelPanel URL + test connection |

## Safari (iOS / macOS)

Convert to a Safari Web Extension using Xcode's built-in tool:

```bash
xcrun safari-web-extension-converter browser-extension/ \
  --app-name "TravelPanel Clipper" \
  --bundle-identifier com.yourname.travelpanel-clipper
```

Then open the generated Xcode project, build, and enable in Safari → Settings → Extensions.

## File structure

```
browser-extension/
  manifest.json      — Manifest V3 extension config
  popup.html         — Toolbar popup (360px wide, dark theme)
  popup.js           — Popup logic (platform detection, preview, clip action)
  background.js      — Service worker (context menu, keyboard shortcut)
  settings.html      — Options page (URL config + connection test)
  settings.js        — Settings logic
  icons/
    icon.svg         — Source SVG (run generate-icons.js to produce PNGs)
    icon16.png       — Generated by generate-icons.js
    icon32.png
    icon48.png
    icon128.png
  generate-icons.js  — PNG icon generator (requires sharp)
```

## Development

After editing JS/HTML files, go to `chrome://extensions` and click the **↺ refresh** button on the extension card.
