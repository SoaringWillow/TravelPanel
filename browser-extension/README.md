# TravelPanel Clipper — Browser Extension

Save travel inspiration from any webpage (Instagram, YouTube, Xiaohongshu, blogs) directly to your TravelPanel boards. One click → AI extracts locations + wisdom.

## Install (Chrome / Edge / Brave)

1. Open `chrome://extensions` (or `edge://extensions`)
2. Enable **Developer mode** (toggle, top-right)
3. Click **Load unpacked**
4. Select this `browser-extension/` folder
5. The TravelPanel icon appears in your toolbar (pin it for easy access)

## First-time setup

Click the extension icon → enter your TravelPanel URL (e.g. `https://your-app.vercel.app`) → **Connect**.

Or open **Settings** (gear icon) and update the URL any time.

## Usage

1. Navigate to any travel page (Instagram post, YouTube video, blog, etc.)
2. Click the TravelPanel icon in the toolbar
3. Optionally edit the title
4. Click **Save to TravelPanel**
5. A new tab opens with TravelPanel's save sheet — choose a board and let AI do the rest

## Files

| File | Purpose |
|------|---------|
| `manifest.json` | Extension manifest (Manifest V3) |
| `popup.html/js/css` | Toolbar popup UI |
| `settings.html/js` | Options/settings page |
| `icons/` | Extension icons (generated by `generate-icons.js`) |
| `generate-icons.js` | Zero-dependency PNG icon generator |

## Regenerate icons

```bash
node generate-icons.js
```

## Firefox

Firefox supports Manifest V3 as of v109. To load:
1. Open `about:debugging#/runtime/this-firefox`
2. Click **Load Temporary Add-on…**
3. Select `manifest.json`

For permanent installation, the extension would need to be signed via AMO.
