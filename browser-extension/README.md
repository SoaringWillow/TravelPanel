# TravelPanel Browser Extension

Clip travel inspiration from any webpage directly into TravelPanel — one click, no fuss.

## Features

- **One-click clipping** — click the toolbar icon to clip the current page with og:image preview
- **Context menu** — right-click any page or link → "Clip to TravelPanel"
- **Keyboard shortcut** — `Alt+Shift+S` clips the current page instantly (configurable)
- **Board selector** — clip directly into a named board or the default Inbox
- **Platform detection** — recognises Instagram, YouTube, 小红书, TikTok, Douyin, Bilibili
- **Manifest V3** — compatible with Chrome 88+ and Safari 15.4+ (via Xcode conversion)

## Setup

### 1. Generate icons (one-time)

```bash
node generate-icons.js
# Creates icons/icon16.png, icons/icon48.png, icons/icon128.png
```

### 2. Load as unpacked extension (Chrome)

1. Open `chrome://extensions/`
2. Enable **Developer mode** (top-right toggle)
3. Click **Load unpacked** → select the `browser-extension/` folder
4. Pin the extension to your toolbar

### 3. Configure your TravelPanel URL

1. Click the extension icon → ⚙️ Settings
2. Enter your TravelPanel URL (e.g. `https://your-app.vercel.app`)
3. Optionally add your custom boards
4. Click **Save Settings**

## Safari Extension (macOS/iOS)

Safari Web Extensions use the same Manifest V3 format. Convert with Xcode:

```bash
xcrun safari-web-extension-converter browser-extension/ \
  --project-location . \
  --app-name "TravelPanel Clipper" \
  --bundle-identifier com.travelpanel.clipper \
  --swift
```

Then open the generated Xcode project, build, and enable in Safari → Preferences → Extensions.

## File Structure

```
browser-extension/
├── manifest.json          # Chrome Manifest V3
├── popup.html             # Toolbar popup UI
├── popup.js               # Popup logic
├── background.js          # Service worker (context menus, commands)
├── content.js             # Metadata extractor (og:title, og:image, etc.)
├── options.html           # Settings page
├── options.js             # Settings logic
├── styles/
│   └── popup.css          # Popup styles
├── icons/
│   ├── icon16.png         # Generated by generate-icons.js
│   ├── icon48.png
│   └── icon128.png
└── generate-icons.js      # Node.js icon generator (no external deps)
```

## Permissions Used

| Permission     | Why |
|----------------|-----|
| `activeTab`    | Read the current tab's URL and title |
| `storage`      | Persist TravelPanel URL + boards + recent clips |
| `contextMenus` | Add right-click "Clip to TravelPanel" menu |
| `scripting`    | Inject content script to extract og:image metadata |

## Keyboard Shortcut

Default: `Alt+Shift+S` (Windows/Linux), `Alt+Shift+S` (Mac).

To change it: `chrome://extensions/shortcuts`
