# TravelPanel Browser Extension

Clip travel inspiration from any website into TravelPanel with one click.

## Features

- **Popup clip**: Click the toolbar icon on any travel page → opens TravelPanel's share flow
- **Context menu**: Right-click any page or link → "Clip to TravelPanel ✈️"
- **Smart detection**: Warns when the current page can't be clipped (browser internal pages)
- **Configurable**: Options page lets you point to your own TravelPanel deployment

## Setup

### 1. Generate icons (first time only)

```bash
cd browser-extension
node make-icons.js
```

### 2. Configure your app URL

Open the Options page (gear icon in the popup) and enter your TravelPanel deployment URL.
Example: `https://your-app.vercel.app`

### 3. Load in Chrome

1. Open `chrome://extensions`
2. Enable **Developer mode** (top-right toggle)
3. Click **Load unpacked**
4. Select this `browser-extension/` folder

### 4. Load in Safari (requires macOS + Xcode)

```bash
xcrun safari-web-extension-converter browser-extension/ \
  --project-location . \
  --app-name TravelPanelExtension
```

Open the generated Xcode project, build it, then enable the extension in Safari → Settings → Extensions.

## File Structure

```
browser-extension/
  manifest.json      — Manifest V3 extension config
  popup.html/js      — Toolbar popup UI
  options.html/js    — Settings page (app URL config)
  background.js      — Service worker (context menu registration)
  make-icons.js      — Generates PNG icons (run once)
  icons/
    icon16.png        — Generated by make-icons.js
    icon48.png
    icon128.png
```

## How It Works

1. User clicks extension icon (or right-clicks → context menu)
2. Extension opens `https://[your-app]/share?url=<page-url>&title=<page-title>`
3. TravelPanel's share page handles board selection + AI extraction
4. Claude extracts spots AND substance (tips, warnings, wisdom) from the page

The substance layer is the moat — competitors extract only pins; TravelPanel extracts the actionable wisdom in the post.
