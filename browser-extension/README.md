# TravelPanel Browser Extension

Clip travel inspiration from any web page into TravelPanel with one click.

## Features

- One-click clip from Instagram, YouTube, Xiaohongshu, TikTok, and any web page
- Automatically detects the platform and shows a colour-coded badge
- Opens TravelPanel's share page with the URL pre-filled — board selection, enrichment, and saving happen in the app
- Configurable TravelPanel URL (Vercel, local dev, or self-hosted)

## Installation

### Prerequisites

1. Generate the icon files (one-time):
   ```bash
   node generate-icons.js
   ```

2. Deploy your TravelPanel app (or use `localhost:3000` for local dev).

### Chrome / Edge / Arc

1. Open `chrome://extensions`
2. Enable **Developer mode** (top right toggle)
3. Click **Load unpacked**
4. Select the `browser-extension/` folder

### Safari

1. Open Xcode → File → New → Target → Safari Web Extension
2. Follow Apple's [Converting a Web Extension for Safari](https://developer.apple.com/documentation/safariservices/converting_a_web_extension_for_safari) guide
3. Or use `xcrun safari-web-extension-converter browser-extension/`

## First-time Setup

After loading the extension:

1. Click the 🗺 icon in the Chrome toolbar
2. Click **Settings** (gear icon) or right-click → Options
3. Paste your TravelPanel app URL (e.g. `https://your-app.vercel.app`)
4. Click **Save Settings**

## Usage

1. Navigate to any travel inspiration page (Instagram post, YouTube video, blog article, etc.)
2. Click the 🗺 TravelPanel icon in the toolbar
3. Review the page title and detected platform
4. Click **Clip to TravelPanel**
5. TravelPanel opens in a new tab — choose a board and save

## Files

| File | Purpose |
|------|---------|
| `manifest.json` | Extension manifest (Manifest V3) |
| `popup.html/css/js` | Popup shown when clicking the toolbar icon |
| `options.html/css/js` | Settings page to configure the app URL |
| `background.js` | Service worker — generates the toolbar icon via OffscreenCanvas |
| `generate-icons.js` | Node.js script to regenerate PNG icons |
| `icons/` | PNG icons generated by `generate-icons.js` |

## Development

To modify the extension:

1. Edit the source files
2. Go to `chrome://extensions` and click the refresh icon on the TravelPanel card
3. Re-open the popup to see changes

To regenerate icons after design changes:
```bash
node generate-icons.js
```
