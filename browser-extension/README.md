# TravelPanel Clipper — Browser Extension

Clip travel inspiration from any webpage directly into your TravelPanel boards.
Works in **Chrome**, **Edge**, and **Safari** (Manifest V3).

---

## Quick Start

### 1. Generate icons

```bash
cd browser-extension
node scripts/generate-icons.js
```

This writes `icons/icon16.png`, `icons/icon48.png`, and `icons/icon128.png`
using only Node.js built-ins — no npm install needed.

### 2. Load in Chrome / Edge

1. Open `chrome://extensions` (or `edge://extensions`)
2. Enable **Developer mode** (top-right toggle)
3. Click **Load unpacked** and select the `browser-extension/` folder
4. The TravelPanel pin icon appears in your toolbar

### 3. Configure

Click the extension icon → **Settings** (gear icon) → enter your TravelPanel URL:

- **Production:** `https://your-app.vercel.app`
- **Local dev:** `http://localhost:3000`

Click **Save Settings**.

### 4. Clip a page

Navigate to any travel inspiration page (Instagram, YouTube, blog, etc.),
click the TravelPanel icon, then **Clip to TravelPanel**.

A TravelPanel share tab opens, pre-filled with the URL and page title. Select a
board and save — extraction runs in the background.

---

## Safari (macOS)

Convert the MV3 extension to a Safari Web Extension using Xcode:

```bash
xcrun safari-web-extension-converter browser-extension/ \
  --project-location . \
  --app-name TravelPanelClipper
```

Open the generated Xcode project, build, and enable the extension in
Safari → Settings → Extensions.

## File Structure

```
browser-extension/
  manifest.json          # MV3 manifest (Chrome, Edge, Firefox, Safari)
  popup/
    popup.html           # Extension popup UI
    popup.js             # Popup logic — reads tab URL, opens share page
  options/
    options.html         # Settings page
    options.js           # Load/save TravelPanel URL to chrome.storage.sync
  icons/
    icon.svg             # Source SVG (128×128)
    icon16.png           # Generated by scripts/generate-icons.js
    icon48.png
    icon128.png
  scripts/
    generate-icons.js    # PNG icon generator (Node built-ins only)
  package.json
```

---

## How It Works

1. Extension popup queries the active tab's URL and title via `chrome.tabs` API
2. User clicks **Clip to TravelPanel**
3. A new tab opens: `<TravelPanel URL>/share?url=<encoded>&title=<encoded>&source=browser-extension`
4. TravelPanel's existing share page handles extraction — same flow as the iOS Share Extension

No backend changes needed. The extension is a thin launcher for the `/share` route.

---

## Permissions

| Permission  | Why                                                        |
|-------------|------------------------------------------------------------|
| `activeTab` | Read the current tab's URL and title (only on user click)  |
| `storage`   | Persist the configured TravelPanel URL across sessions     |

No browsing history, no background data collection.
