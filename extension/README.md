# TravelPanel Browser Extension

Clip travel inspiration from any webpage into TravelPanel. Uses Claude AI to extract locations and wisdom in seconds.

## Features

- **One-click clipping** — clip the current page or paste any URL
- **AI extraction preview** — see locations and tips before saving
- **Board routing** — opens TravelPanel's share page to choose your destination board
- **Works anywhere** — travel blogs, Instagram, YouTube, Xiaohongshu, any URL

## Installation

### Chrome / Edge / Brave

1. Open `chrome://extensions` (or `edge://extensions`)
2. Enable **Developer mode** (top-right toggle)
3. Click **Load unpacked**
4. Select this `extension/` folder
5. The TravelPanel pin icon appears in your toolbar

### Safari (macOS)

Safari requires converting the extension via Xcode:

```bash
# Install xcrun safari-web-extension-converter (requires Xcode 14+)
xcrun safari-web-extension-converter /path/to/extension/ \
  --project-location ~/Desktop \
  --app-name "TravelPanel Clipper"
```

Then open the generated Xcode project, run it, and enable the extension in Safari → Settings → Extensions.

## Configuration

After installing:

1. Click the extension icon → ⚙️ Settings
2. Set your **TravelPanel URL** (e.g., `https://your-app.vercel.app`)
3. Click **Test Connection** to verify
4. Click **Save Settings**

For local development, use `http://localhost:3000`.

## How It Works

1. Navigate to a travel blog, social post, or any webpage
2. Click the TravelPanel extension icon
3. Click **Clip This Page** → Claude extracts locations + wisdom
4. Review the preview (locations found, tips extracted)
5. Click **Save to TravelPanel** → the share page opens to choose a board
6. Done!

## Development

The extension is a plain Chrome Manifest V3 extension — no build step required.

Files:
- `manifest.json` — extension config
- `popup.html/js/css` — the popup UI
- `background.js` — service worker (sets the icon)
- `options.html/js` — settings page
- `icons/` — 16×48×128px PNG icons (generated by `../scripts/generate-extension-icons.py`)

To regenerate icons:
```bash
python3 scripts/generate-extension-icons.py
```
